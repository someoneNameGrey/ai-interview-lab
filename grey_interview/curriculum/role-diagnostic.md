You are preparing for Backend SWE on AI teams, GenAI SWE and Applied AI Engineer roles. The primary role reference is OpenAI Applied AI Engineer, Singapore. Keep production software engineering central; model training and ML research are optional references.

Start with evidence, not a checklist of frameworks. Record a shipped product's user problem, your own code/design contribution, an alternative you rejected, a measured result and a limitation. ## Worked example
A fictional engineer says: “I implemented idempotent import jobs after duplicate callbacks caused repeated work. Restart and duplicate-delivery tests supported the design. I have not measured multi-region behavior.” This is stronger than an unsupported “built a scalable AI platform.”

Run the diagnostic without AI. Explain an API contract, failure handling and tests. If Python syntax is slow, use the optional Python refreshers; if durable acceptance is unclear, use design-basics and design-reliability. You may open any lesson; prerequisites describe learning order rather than hard locks.
